# OracleAI Trainer (MFactory)

Учебная фабрика нейросетей. Программа, в которой можно собрать и обучить
свою первую нейросеть — без подготовки, с подсказками на каждом шаге.

Делалась для школьного курса по машинному обучению. Внутри есть помощник
«Оракул», который объясняет происходящее обычными словами.

## Как это выглядит

Ученик проходит весь путь: выбирает данные, собирает архитектуру, настраивает
обучение, запускает, смотрит результат и сохраняет модель. Знать заранее
ничего не нужно — на каждом шаге есть готовые варианты и объяснения.

Сломать компьютер здесь нельзя. Все параметры ограничены безопасными
значениями, тяжёлые операции контролируются по памяти и времени.

## Что внутри

- **Датасеты** — свои данные или готовые примеры, мастер подготовки
- **Архитектуры** — трансформеры, RNN, CNN, VAE, без написания кода
- **Гиперпараметры** — скорость обучения, батч, эпохи, с пояснением каждого
- **Обучение** — запуск, графики, метрики, контрольные точки
- **Проверка** — тестирование модели прямо в окне программы
- **Экспорт** — сохранение результата
- **Оракул** — помощник: подсказки, ответы на вопросы, режим «Мастер»
- **Профили** — у каждого ученика свои проекты
- **Администратор** — наблюдение за памятью, процессором, видеокартой

## Установка

Нужен Windows и Python 3.12 с [python.org](https://www.python.org/downloads/).
При установке отметьте галочку «Add Python to PATH».

Скачайте проект кнопкой **Code → Download ZIP** и распакуйте. Или через git:

```powershell
git clone https://github.com/lordsmerti123-coder/MFactory.git
cd MFactory
```

Создайте окружение и поставьте зависимости:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

PyTorch ставится отдельно — в `requirements.txt` написано как. Есть два
варианта: с поддержкой видеокарты и без.

Запуск:

```powershell
python main.py
```

Откроется главное окно.

## Видеокарта

Программа работает и с видеокартой, и без неё. Внутри это выглядит так:

```python
# core/trainer.py
self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

Есть NVIDIA — обучение идёт на ней. Нет — на процессоре, медленнее,
но всё работает. Переключать ничего не надо.

В панели администратора видно состояние. Если видеокарты нет, там написано
«GPU: недоступен (CUDA выключена)» — это нормально, не ошибка.

Учебные модели здесь маленькие, от 80 тысяч параметров, поэтому даже
на процессоре обучение занимает секунды или минуты.

Видеокарты AMD обычная установка PyTorch не поддерживает — нужна отдельная
пересборка. Для курса это не требуется, используйте вариант без видеокарты.

## Оракул

Оракул отвечает на вопросы и объясняет, что происходит на экране.
Работает в четырёх режимах, переключаются в главном окне:

- `hybrid` — ИИ, если доступен, иначе обычные подсказки. Режим по умолчанию
- `static` — только заранее заготовленные подсказки
- `ai` — только ответы модели
- `none` — подсказки выключены

**Скачивать модель для курса не обязательно.** По умолчанию Оракул работает
без неё: отвечает из встроенной базы знаний и даёт обычные подсказки.
Всё обучение нейросетей работает и так.

### Если хочется живых ответов

У Оракула два источника. Работает тот, что настроен; если оба, то сначала
проверяется локальная модель.

**Локальная модель.** Файл GGUF на диске, считается на вашем компьютере.
Интернет не нужен, ничего никуда не уходит. Это основной вариант.

**Облачный API.** Яндекс GPT или Сбер GigaChat по ключу. Нужен интернет,
и текст запросов уходит на чужой сервер. Если разговор должен остаться
приватным — используйте локальную модель.

Для Яндекса нужны `api_key` и `folder_id`, для Сбера — `client_id`
и `client_secret`. Ключи вводятся в настройках Оракула и сохраняются
в `data/system/oraculum_settings.json`. Этот файл в `.gitignore`
и в репозиторий не попадает.

### Подключение локальной модели

Скачайте `YandexGPT-5-Lite-8B-instruct-Q4_K_M.gguf` (около 4.7 ГБ)
с HuggingFace, репозиторий `yandex/YandexGPT-5-Lite-8B-instruct-GGUF`.
Программа сама модель не качает — файл кладётся вручную.

Положите файл в папку проекта. Имя должно совпадать: программа ищет его
по списку `ORACULUM_GGUF_CANDIDATES` в `config.py`. Запустите программу —
Оракул найдёт модель и начнёт использовать.

Настройки в `config.py`:

```python
ORACULUM_GGUF_CTX_SIZE      = 2048   # размер контекста, меньше — надёжнее
ORACULUM_GGUF_N_GPU_LAYERS  = None   # None = определить автоматически
ORACULUM_GGUF_MAX_TOKENS    = 256    # длина ответа
ORACULUM_LOCAL_GEN_TIMEOUT  = 90     # защита от зависания, секунды
```

Про видеокарту настраивать нечего: при запуске программа проверяет CUDA.
Есть — все слои идут на неё, нет — на процессор. Можно задать вручную:
`-1` всё на видеокарту, `0` на процессор.

Если появится ошибка `Failed to load shared library ... llama.dll` — не
хватает библиотек CUDA, под которые собрана `llama-cpp-python`. Разбор
этого случая в [docs/llama_cpp_yandexgpt_setup.md](docs/llama_cpp_yandexgpt_setup.md).

## Что где лежит

```
MFactory/
├── main.py              — запуск программы
├── config.py            — настройки: пути, лимиты, значения по умолчанию
│
├── core/                — логика без интерфейса
│   ├── oraculum/        — Оракул: агент, база знаний, локальная модель, мастер
│   ├── model_factory.py — сборка архитектур
│   ├── trainer.py       — цикл обучения
│   ├── data_loader.py   — загрузка и подготовка данных
│   ├── contracts.py     — общие типы данных
│   └── ...
│
├── gui/                 — интерфейс
│   ├── main_window.py   — главное окно
│   ├── panels/          — панели: данные, архитектуры, обучение и другие
│   └── widgets/         — свои элементы интерфейса
│
├── docs/                — дополнительная документация
└── tests/               — тесты
```

Папка `data/` создаётся при первом запуске. Там профили учеников, датасеты,
модели, журналы. В репозиторий она не входит.

## Справочник по датасетам

В [docs/DATASET-REQUIREMENTS.md](docs/DATASET-REQUIREMENTS.md) написано,
какой датасет нужен каждой архитектуре: тип данных, формат записей, размер,
особые требования. Пригодится, когда ученик готовит свои данные и не
понимает, почему обучение не идёт.

## Как проверить, что всё работает

```powershell
venv\Scripts\python.exe -m pytest tests -q
```

Должно пройти 148 тестов.

## Известные особенности

**Первый запуск медленнее.** PyTorch компилирует ядра под вашу видеокарту.
Это разово.

**Оракул может подолгу думать.** Если генерация зависла, сработает таймаут,
и модель пометится как зависшая. Дальше вызовы отклоняются до перезагрузки.

**Кириллица в консоли.** В Windows консоль может показывать русский текст
нечитаемо. В интерфейсе программы всё нормально.
